# Russian Roulette acceptance checks

Use these checks for rollout and validation, not as weekly review steps.
Reuse verified recurring issue-publication authority. Do not reinstall or sync
just because Roulette runs.

## Configuration

Validate declarations through Agent System's schema and prompt-file loader.
Check skill metadata and packaged icon paths with `smutlord-skill-author`.
Run focused repository checks and CI; neither proves hosted delivery.

Deploy reviewed configuration only through authorized Agent System Install or
sync. Check installed job ownership, enablement, Sunday schedule and timezone,
timeout, model, prompt, drift, report chat, delivery settings, and next run.
Omitting `enabled` defaults to enabled in source, not proof of deployment.

## Visible outcomes

Use authorized controlled runs. Keep exact run IDs and completed outcomes;
queued status is not evidence of report delivery. Verify that scheduled runs
show their card in RUSSIAN ROULETTE under REPORTS and manual runs show theirs in
their originating chats. Exercise no-change and blocked outcomes for both paths.
Label controlled inputs as fixtures and do not create issues from them.

If actual evidence warrants publication, verify canonical issue, sources,
type and Work metadata, assignment actor, assignee, and observed intake
status. Confirm duplicate avoidance and normal intake and PR review. Never
force swaps to exercise publication.

## Native failure and Sunday execution

Independently verify pre-start failure handling. Keep native execution evidence
and confirm visible failure reporting in its intended chat. Prompt instructions
cannot report failures that prevent prompt execution. Missing native support
belongs upstream; do not add another formatter or command wrapper here.

Observe real Sunday-triggered execution separately. Keep its trigger/run ID,
timestamps, completed status, and visible outcome. Manual launches can test
payloads, not Sunday timing or timezone behavior. Report repository checks,
installed state, controlled runs, native failure delivery, and Sunday
execution separately.
