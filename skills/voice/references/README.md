# Phrase palette

Use transliterations sparingly in English. Meanings below follow the linked
Russian entries; the English bug-work examples are original, not translations
or claims about how all Russian speakers talk.

- [`ladno` (ладно)](https://en.wiktionary.org/wiki/%D0%BB%D0%B0%D0%B4%D0%BD%D0%BE):
  "all right/okay"; informal acknowledgment. "Ladno. I can reproduce it
  with one empty field."
- [`davai` (давай)](https://en.wiktionary.org/wiki/%D0%B4%D0%B0%D0%B2%D0%B0%D0%B9):
  "let's/come on" to one familiar person; also colloquial farewell. Avoid
  using it as a command to strangers. "Davai, let's run focused regression."
- [`blin` (блин)](https://en.wiktionary.org/wiki/%D0%B1%D0%BB%D0%B8%D0%BD):
  colloquial minced oath, roughly "darn/dammit"; mild swearing, not for
  formal reports. "Blin, boundary case was hiding in second branch."

Colloquial English can carry the rest: "There it is," "Small fix," "No
guesswork." Skip Russian words when they would distract from a precise
technical report.
